# 欢迎使用 TabMd

TabMd 是一个零依赖的 Markdown 管理器：**左侧列出同级 `md/` 目录下的所有 `.md` 文件，点一下就弹出新窗口编辑。**

## 快速开始

```bash
cd 本目录
python3 server.py        # 默认 http://localhost:8848
```

启动后浏览器会自动打开页面；如果没开，手动访问 http://localhost:8848

## 三种工作模式

| 模式 | 触发条件 | 读取 | 保存 |
| --- | --- | --- | --- |
| 本地服务 | 运行 `server.py` | ✅ | ✅ 直接写回磁盘 |
| 静态 | 存在 `md/manifest.json` | ✅ | ⚠️ 只能下载后手动覆盖 |
| 本地文件夹 | 点「选择文件夹」授权 | ✅ | ✅ 需要 Chrome / Edge |

> 用 `file://` 直接双击打开页面时，浏览器不允许读取目录，会提示你手动选一次 `md` 文件夹。

## 快捷键（编辑窗口）

- `Ctrl / ⌘ + S` 保存
- `Ctrl / ⌘ + B` 加粗
- `Ctrl / ⌘ + I` 斜体
- `Tab` 缩进两个空格

---

双击左侧任意文件，或点行尾的「打开」按钮，即可**弹出新窗口**编辑。

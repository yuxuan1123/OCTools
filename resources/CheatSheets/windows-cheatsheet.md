# Windows Keyboard Shortcuts for Developers

<a id="general-shortcuts"></a>
## General Shortcuts

| Command | Description |
| :-----: | ----------- |
| `F1` | 显示帮助 |
| `Ctrl + X` | 剪切所选项 |
| `Ctrl + C` | 复制所选项 |
| `Ctrl + V` | 粘贴所选项 |
| `Ctrl + Z` | 撤销操作 |
| `Ctrl + Y` | 重做操作 |
| `Ctrl + A` | 全选 |
| `Ctrl + F` | 查找 |
| `Ctrl + P` | 打印 |
| `Ctrl + S` | 保存 |
| `Ctrl + T` | 打开新标签页 |
| `Ctrl + O` | 打开 |
| `Ctrl` + `+` | 放大尺寸 |
| `Ctrl` + `-` | 缩小尺寸 |
|` Ctrl + D`| 删除所选项并将其移动到回收站|
|` Ctrl + E`| 打开搜索（在大多数应用中）|
|` Ctrl + R`| 刷新活动窗口|
|` Ctrl + Right arrow`| 将光标移动到下一个单词的开头|
|` Ctrl + Left arrow`| 将光标移动到上一个单词的开头|
|` Ctrl + Down arrow `| 将光标移动到下一段的开头|
|` Ctrl + up arrow`| 将光标移动到上一段的开头|

<a id="windows-keys-shortcuts"></a>
## Windows Keys Shortcuts

| Command | Description |
| :-----: | ----------- |
| `Win` | 显示或隐藏"开始"屏幕 |
| `Win + ,` | 按住按键时查看桌面 |
|` Win + D`| 显示和隐藏桌面|
| `Win + E` | 打开文件资源管理器 |
|` Win + L`| 锁定电脑|
| `Win + V` | 查看剪贴板和表情符号 |
|` Win + X`| 打开快捷链接菜单|
|` Win + Tab`| 打开任务视图|
|` Win + M`| 最小化所有窗口 |
|` Win + R`| 打开"运行"对话框 |
|` Win + A`| 打开操作中心 |
|` Win + C`| 以聆听模式启动 Cortana（用于语音命令） |
|` Win + S`| 搜索/启动 Cortana（聆听模式） |
|` Win + Ctrl + D`| 创建新虚拟桌面 |
|` Win + Ctrl + F4`| 关闭当前桌面 |
| `Win + Ctrl + Left Arrow Key` <br /> `Win + Ctrl + Right Arrow Key` | 在虚拟桌面之间切换 |
| `Win + Left Arrow Key` <br /> `Win + Right Arrow Key` | 将当前窗口贴靠到左侧或右侧 |
|` Win + PrtScn` <br/> ` Fn + Win + Spacebar`| 用于截屏|
|` Win + Shift + S`| 截取所选区域的屏幕截图|
|` Win + Upper Arrow key`| 最大化窗口|
| `Win + number key` | 通过任务栏上带编号的键位打开应用 |
| `Win + Alt + R` | 允许你立即开始或停止录制屏幕 |

<a id="command-prompt-shortcuts"></a>
## Command Prompt Shortcuts

| Gesture | Description |
| :-----: | ----------- |
| `Ctrl + Up arrow` | 在输出历史中向上移动一行。 |
| `Ctrl + Down arrow` | 在输出历史中向下移动一行。 |
| `Ctrl + M` | 进入标记模式。 |
| `Ctrl + Home (Mark mode)` | 将光标移动到缓冲区开头 |
| `Ctrl + End (Mark mode)` | 将光标移动到缓冲区结尾。 |
| `Ctrl + Home (History navigation)` | 如果命令行已空，将视口移动到缓冲区顶部。否则，删除命令行中光标左侧的所有字符。 |
| `Ctrl + End (History navigation)` | 如果命令行已空，将视口移动到命令行。否则，删除命令行中光标右侧的所有字符。 |

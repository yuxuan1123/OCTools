# 面向开发者的 Chrome DevTools 键盘快捷键

## 打开 DevTools 的键盘快捷键

| Windows / Linux | Mac | 说明 |
| :-------------: | :-: | :---------: |
| `Ctrl + Shift + J` | `Cmd(⌘) + Option(⌥) + J` | 打开___控制台___面板 |
| `Ctrl + Shift + C` | `Cmd(⌘) + Shift + C` 或<br />`Cmd(⌘) + Option(⌥) + C` | 打开___元素___面板 |
| `F12` 或<br /> `Ctrl + Shift + I` | `Cmd(⌘) + Option(⌥) + I` | 打开上次使用的面板 |

## 全局键盘快捷键

| Windows / Linux | Mac | 说明 |
| :-------------: | :-: | :---------: |
| `Ctrl + ]` | `Cmd(⌘) + ]` | 聚焦下一个面板 |
| `Ctrl + [` | `Cmd(⌘) + [` | 聚焦上一个面板 |
| `Ctrl + Shift + M` | `Cmd(⌘) + Shift + M` | 切换设备模式 |

| `Ctrl + F5` 或<br /> `Ctrl + Shift + R` | `Cmd(⌘) + Shift + R` | 强制重新加载 |
| `Ctrl + Shift + +` | `Cmd(⌘) + Shift + +` | 放大 |
| `Ctrl + -` | `Cmd(⌘) + -` | 缩小 |
| `Ctrl + 0` | `Cmd(⌘) + 0` | 恢复默认缩放级别 |
| `Ctrl + Shift + P` | `Cmd(⌘) + Shift + P` | 打开命令菜单 |
| `Ctrl + F` | `Cmd(⌘) + F` | 在当前面板中搜索文本。仅在___元素___、___控制台___、___源代码___、___性能___、___内存___、___JavaScript 分析器___和___快速源___面板中受支持。 |

## 元素面板键盘快捷键

| Windows / Linux | Mac | 说明 |
| :-------------: | :-: | :---------: |
| `Ctrl + Z` | `Cmd(⌘) + Z` | 撤销更改 |
| `Ctrl + Y` | `Cmd(⌘) + Shift + Z` | 重做更改 |
| `右箭头(→)` | `右箭头(→)` | 展开当前选中的节点。<br />如果节点已展开，此快捷键会选择其下方的元素 |
| `左箭头(←)` | `左箭头(←)` | 折叠当前选中的节点。<br />如果节点已折叠，此快捷键会选择其上方的元素 |
| `回车(↵)` | `回车(↵)` | 在当前选中元素上切换**编辑属性**模式 |
| `H` | `H` | 隐藏当前选中的元素 |
| `Function + F2` | `F2` | 在当前选中元素上切换**作为 HTML 编辑**模式 |

## 样式窗格键盘快捷键

| Windows / Linux | Mac | 说明 |
| :-------------: | :-: | :---------: |
| 按住 `Ctrl` 并点击属性值 | 按住 `Cmd(⌘)` 并点击属性值 | 跳转到属性值声明所在的行 |
| 按住 `Shift` 并点击值旁边的<br />**颜色预览**框 | 按住 `Shift` 并点击值旁边的<br />**颜色预览**框 | 循环切换颜色的 RGBA、HSLA 和 Hex 表示形式 |
| 点击属性名称或值，然后按 `Tab(↹)` 或 `Shift + Tab(↹)` | 点击属性名称或值，然后按 `Tab(↹)` 或 `Shift + Tab(↹)` | 选择下一个/上一个属性或值 |
| 点击一个值，然后按 `上箭头(↑)` 或 `下箭头(↓)` | 点击一个值，然后按 `上箭头(↑)` 或 `下箭头(↓)` | 将属性值增加/减少 1 |
| 点击一个值，然后按 `Shift + 上箭头(↑)` 或 `Shift + 下箭头(↓)` | 点击一个值，然后按 `Shift + 上箭头(↑)` 或 `Shift + 下箭头(↓)` | 将属性值增加/减少 10 |
| 点击一个值，然后按 `Ctrl + 上箭头(↑)` 或 `Ctrl + 下箭头(↓)` | 点击一个值，然后按 `Cmd(⌘) + 上箭头(↑)` 或 `Cmd(⌘) + 下箭头(↓)` | 将属性值增加/减少 100 |

## 源代码面板键盘快捷键

| Windows / Linux | Mac | 说明 |
| :-------------: | :-: | :---------: |
| `F8` 或<br />`Ctrl + \` | `F8` 或<br />`Cmd(⌘) + \` | 暂停脚本执行（如果正在运行）或<br />继续执行（如果已暂停） |
| `F10` 或<br />`Ctrl + '` | `F10` 或<br />`Cmd(⌘) + '` | 单步跳过下一个函数调用 |
| `F11` 或<br />`Ctrl + ;` | `F11` 或<br />`Cmd(⌘) + ;` | 单步进入下一个函数调用 |
| `Shift + F11` 或<br />`Ctrl + Shift + ;` | `Shift + F11` 或<br />`Cmd(⌘) + Shift + ;` | 单步跳出当前函数 |
| `Ctrl + S` | `Cmd(⌘) + S` | 保存对本地修改的更改 |
| `Ctrl + Alt + S` | `Cmd(⌘) + Option(⌥) + S` | 保存所有更改 |
| `Ctrl + G` | `Ctrl + G` | 跳转到行 |
| `Alt + W` | `Option(⌥) + W` | 关闭活动标签页 |
| `Ctrl + Shift + Y` | `Cmd(⌘) + Shift + Y` | 切换左侧的**导航**侧边栏 |
| `Ctrl + Shift + H` | `Cmd(⌘) + Shift + H` | 切换右侧的**调试器**侧边栏 |

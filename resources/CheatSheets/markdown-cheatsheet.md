# Markdown 面向开发者速查表

<a id="basic-syntax"></a>
## 基础语法

| Command                                 | Description                                          |
| --------------------------------------- | ---------------------------------------------------- |
| `**bold text**` <br /> `__bold text__`  | 加粗                                                 |
| `*italic text*` <br /> `_italic text_`  | 斜体                                                 |
| `# h1` <br /> `## h2` <br /> `### h3`   | # 标题 1 <br /> ## 标题 2 <br /> ### 标题 3          |
| `[hello google](http://www.google.com)` | 导入链接                                             |
| `- first` <br /> `- second`             | 无序列表                                             |
| `1. first` <br /> `2. Second`           | 有序列表                                             |
| `---`                                   | 水平线                                               |
| `![alt text](image.jpg)`                | 导入图片                                             |

<a id="extended-syntax"></a>
## 扩展语法

| Command                                                                                                   | Description       |
| --------------------------------------------------------------------------------------------------------- | ----------------- |
| `X^2^`                                                                                                    | 上标              |
| `H~2~O`                                                                                                   | 下标              |
| `I need to highlight these ==very important words==.`                                                     | ==高亮==          |
| `That is so funny! :joy:`                                                                                 | 表情符号          |
| `~~The world is flat.~~ `                                                                                 | ~~删除线~~        |
| `> blockquote`                                                                                            | > 块引用          |
| ` ``` ` <br /> `{ ` <br /> `"First": "1st",` <br /> `"Second": "2nd"` <br /> ` }` <br /> ` ``` `            | 围栏代码块        |
| ` - [x] task one` <br /> `- [ ] task two` <br /> `- [ ] task three` <br />                                | 任务列表          |
| `\| col1 \| col2 \|` <br /> `\|------\|------\| ` <br /> `\|data1 \|data2 \|` <br /> `\|data3 \|data4 \|` | 表格              |
| `Here's a sentence with a footnote. [^1] ` <br /> `[^1]: This is the footnote.`                           | 脚注              |

# NPX（Node 包执行器）面向开发者速查表

<a id="basic-commands"></a>
## 基础命令

| Command | Description |
| :-------: | :-----------: |
| `npx create-react-app [name]` | 创建一个 react 应用 |
| `npx npm-check -u` | 更新所有项目依赖 |
| `npx browserslist` <br /> OR <br /> `npx browserslist "last 2 versions, not dead, not < 2%"` | 浏览器列表 |
| `npx create-react-app {name} --template {template}` | 可根据开发者需要添加模板，例如 redux 模板，<br /> `npx create-react-app my-app --template redux` |
|`npx sirdeploy reactapp .`| 在 Github 上部署 React 应用|

# VSCode Keyboard Shortcuts for Developers

<a id="general-shortcuts"></a>
## General Shortcuts

| Command | Description |
| ------- | ----------- |
| `Ctrl + Shift + P` | 显示命令面板 |
| `Ctrl + Shift + X` | 显示扩展 |

## Basic Editing

| Command | Description |
| ------- | ----------- |
| `Ctrl + A` | 全选 |
| `Ctrl + C` | 复制行 |
| `Ctrl + D` | 复制行 |
| `Ctrl + L` | 选择当前行 |
| `Ctrl + X` | 剪切行 |
| `Ctrl + U` | 撤销上一次光标操作 |
| `Ctrl + V` | 粘贴 |
| `Ctrl + Y` | 重做更改 |
| `Ctrl + Z` | 撤销更改 |
| `Alt + Down` | 将行下移 |
| `Alt + Up` | 将行上移|

<a id="multi-cursor-and-selection"></a>
## Multi-cursor and Selection

| Command | Description |
| ------- | ----------- |
| `Alt + Click` | 插入光标 |
| `Shift + Alt + UpArrow` | 向上复制行 |
| `Shift + Alt + DownArrow` | 向下复制行 |
| `Shift + Alt + Click` | 以块方式选择文本 |
| `Ctrl + Alt + UpArrow` | 在上方添加光标 |
| `Ctrl + Alt + DownArrow` | 在下方添加光标 |
| `Ctrl + Shift + K` | 删除行 |
| `Ctrl + Shift + L` | 选择当前选择的所有匹配项 |

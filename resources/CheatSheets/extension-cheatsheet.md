# Extension CheatSheet for Developers

<a id="vscode-extensions"></a>
## VSCode Extensions

| 扩展 | 说明 |
| :--------: | ----------- |
| `Auto Import` | 自动查找、解析并为所有可用导入提供代码操作和代码补全。支持 Typescript 和 TSX。 |
| `C/C++` | C/C++ 智能感知、调试和代码浏览。 |
| `Code Runner` | 运行多种语言的代码片段或代码文件：C、C++、Java、JavaScript、PHP、Python、Perl、Perl 6、Ruby、Go、Lua、Groovy、PowerShell、BAT/CMD、BASH/SH、F# Script、F# (.NET Core)、C# Script、C# (.NET Core)、VBScript、TypeScript、CoffeeScript、Scala、Swift、Julia、Crystal、OCaml Script、R、AppleScript、Elixir、Visual Basic .NET、Clojure、Haxe、Objective-C、Rust、Racket、Scheme、AutoHotkey、AutoIt、Kotlin、Dart、Free Pascal、Haskell、Nim、D、Lisp、Kit、V、SCSS、Sass、CUDA、Less、Fortran、Ring、Standard ML，以及自定义命令 |
| `Code Spell Checker` | 源代码拼写检查器 |
| `ES7 + React/Redux/React-Native snippets` | 用于 JS/TS 中 React、React-Native 和 Redux 的扩展，使用 ES7+ 语法。可自定义。内置与 prettier 集成 |
| `ESLint` | 将 ESLint JavaScript 集成到 VS Code 中。 |
| `HTML Boilerplate` | 一个基础的 HTML5 模板片段生成器。 |
| `HTML CSS Support` | HTML 的 CSS 智能感知 |
| `HTML Snippets` | 完整的 HTML 标签，包括 HTML5 片段 |
| `IntelliCode` | AI 辅助开发 |
| `IntelliCode API Usage Examples` | 在编辑器中直接查看来自 GitHub 的超过 10 万种不同 API 的相关代码示例。 |
| `JavaScript (ES6) code snippets` | ES6 语法的 JavaScript 代码片段 |
| `JS JSX Snippets` | 用于 JS 中 React、Redux 的扩展，使用 babel 和 ES7 语法 |
| `JSX HTML <tags/>` | 在 JSX 中使用 HTML 标签 |
| `Live Server` | 启动一个带实时重载功能的本地开发服务器，用于静态和动态页面 |
| `Markdown ALl in One` | 编写 Markdown 所需的一切（键盘快捷键、目录、自动预览等） |
| `npm` | VS Code 的 npm 支持 |
| `npm Intellisense` | 在导入语句中自动补全 npm 模块的 Visual Studio Code 插件 |
| `Path Intellisense` | 自动补全文件名的 Visual Studio Code 插件 |
| `React Extension Pack` | 用于 React 开发的流行 VS Code 扩展 |
| `Reactjs code snippets` | ES6 语法的 React-js 开发代码片段 |
| `Search node_modules` | 快速搜索 node_modules 文件夹。 |
| `Simple React Snippets` | 你会真正用到的极简 React 片段 |
| `Tailwind CSS IntelliSense` | VS Code 的智能 Tailwind CSS 工具 |

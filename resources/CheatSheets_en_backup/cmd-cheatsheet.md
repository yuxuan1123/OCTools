# RAA（以管理员身份运行）

## 文件和文件夹管理：

| 命令 | 描述 |
| :-----------------: | --------------------------------------------------------------------------------------------- |
| `?` | 帮助，有时显示某些命令的相关命令。 |
| `ls` | 显示当前目录中的所有现有文件夹 |
| `cd` | - 更改目录 <br /> - `cd 目录名`。 |
| `copy` | 将文件复制到其他位置 |
| `dir` | 列出目录内容。 |
| `del` | 用于删除一个或多个文件。 |
| `expand` | 解压缩压缩文件。 |
| `fc` | 文件比较 - `fc a.txt b.txt`。 |
| `find` | 查找文件。 |
| `ftype` | 显示文件类型和映射。 |
| `mkdir` | 创建目录。 |
| `move` | 将文件从一个文件夹移动到另一个文件夹。 |
| `print` | 打印文本文件的内容。 |
| `rm` | - 从任何目录中删除文件 <br /> - `rm 文件名`。 |
| `rd` / `rmdir` | - 删除目录 <br /> - `rmdir [目录]` <br /> - `rd [目录]` |
| `rmdir /s` | - 删除任何主文件夹下的所有子文件夹 <br /> - `rmdir /s 文件夹名`。 |
| `dir /a` | 此命令有助于查找所有隐藏目录 |
| `ren` | 重命名。 |
| `replace` | 用一个目录中的文件替换另一个目录中同名的文件。 |
| `robocopy` | 使用高级工具复制文件和目录。 |
| `tree` | 以树状方式显示所有系统文件夹。 |
| `type` | 显示文本文件的内容。 |
| `xcopy` | xcopy 命令可以将一个或多个文件或目录树从一个位置复制到另一个位置。 |

## 应用程序和进程：

| 命令 | 描述 |
| :--------: | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `schtasks` | 执行命令或启动计划任务（任务计划程序）。 |
| `shutdown` | - 关闭计算机，使用附加命令控制系统关机 <br /> - `shutdown` <br /> - `shutdown/?` <br /> - `shutdown/i` |
| `tasklist` | 显示当前正在运行的任务列表 |
| `taskkill` | - 终止正在运行的任务 <br /> - `taskkill /im [程序名]` <br /> - `taskkill /im notepad.exe` <br /> - `taskkill /f /im notepad.exe` |
| `reg` | 启动注册表编辑器 |
| `runas` | 以其他用户身份启动任务 |

**#目录**

## 磁盘管理：

| 命令 | 描述 |
| :-------------------------: | -------------------------------------------------------------------------------------------------- |
| `chkdsk` | - 扫描磁盘/驱动器错误 <br /> - `chkdsk [磁盘名]:` <br /> - `chkdsk C:` |
| `defrag` | 启动磁盘碎片整理。 |
| `compact` | 显示并更改 NTFS 分区中文件的压缩状态。 |
| `format` | 格式化磁盘。 |
| `Recover` | 从损坏的磁盘中恢复数据。 |
| `sfc` | - 系统文件检查器，扫描所有系统文件并在必要时修复它们 <br /> - `sfc /scannow` |
| `vol` | 显示磁盘的卷标和序列号。 |
| `wmic logicaldisk get name` | 获取所有驱动器名称 |
| `diskmgmt.msc` | 从命令提示符打开磁盘管理系统 |

## 系统信息：

| 命令 | 描述 |
| :----------: | ------------------------------------------------------------------------------------ |
| `date` | 显示/设置日期。 |
| `hostname` | 显示计算机的主机名。 |
| `powercfg` | - 提供电源设置报告 <br /> - `powercfg /?` <br /> - `powercfg /list` |
| `systeminfo` | 获取系统相关信息。 |
| `time` | 显示或设置系统时间。 |
| `ver` | 显示操作系统版本。 |
| `finger` | 关于用户的信息。 |
| `whois` | 当用户想要查找域名或 IP 地址时，此命令很有用。 |
| `ftp` | 将文件传输到 FTP 服务器。 |
| `getmac` | 显示 MAC 地址。 |
| `mode` | 用于配置系统设备。 |
| `print` | 将指定的文本文件打印到指定的打印设备。 |

**#目录**

## 网络：

| 命令 | 描述 |
| :----------: | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ipconfig` | 显示 IP 网络设置。 |
| `ping` | - 测试源计算机能否到达指定的目标计算机 <br /> - 在 cmd 中显示___用法___和___选项___列表 <br /> - 从网站网络获取响应 <br /> - `ping [网站名]` <br /> - `ping [IP 地址]` |
| `nslookup` | 通过资源名称查找 IP 地址。 |
| `route` | 此命令用于检查和修改计算机的路由表。 |
| `arp` | 显示一个表格，其中包含 IP 地址转换成的物理地址。 |
| `netsh` | - 允许你显示或修改当前正在运行的计算机的网络配置 <br /> - 用于各种网络相关属性的命令 <br /> - `netsh`（步骤 1） <br /> - `netsh> /?` |
| `netsh wlan` | - netsh 的命令扩展 <br /> - `netsh`（步骤 1） <br /> - `netsh> wlan /?` |

## 命令行设置：

| 命令 | 描述 |
| :-----------: | ------------------------------------------------------------------------------ |
| `cls` | 清屏。 |
| `color` | 更改文本和背景颜色。 |
| `echo` | 打印 echo 后面的文本一次。 |
| `prompt` | 更改命令提示符（打印后面的文本，直到关闭 cmd） |
| `pause` | 暂停窗口，直到你按下任意键。 |
| `title` | 设置命令提示符的标题。 |
| `timeout xxx` | 终端倒计时等待 - xxx 为秒数。 |
| `exit` | 退出 cmd 窗口。 |
| `reset` | reset 命令执行为重置会话。 |
